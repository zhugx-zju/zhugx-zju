# Gengxuan Zhu · 朱耕玄

PhD student in solid mechanics at Zhejiang University. I study inverse problems in mechanics, with a focus on reconstructing spatially varying material properties from displacement measurements.

## Featured projects

| Project | What it covers |
| --- | --- |
| [FE-GIN](https://github.com/zhugx-zju/FE-GIN) | Finite-element-guided neural network for full-field modulus reconstruction in functionally graded materials. Includes MATLAB data generation, PyTorch training with weak-form equilibrium losses, and comparisons with adjoint inversion. [Paper](https://doi.org/10.1016/j.ijmecsci.2026.112126) |
| [CHTC](https://github.com/zhugx-zju/CHTC) | Code accompanying my work on continuous high-throughput characterization of mechanical properties via deep learning. [Paper](https://doi.org/10.1016/j.ijmecsci.2025.110137) |
| [ASM-Python](https://github.com/zhugx-zju/ASM-Python) | Python finite element solver for 2D graded materials, with adjoint-state modulus inversion, gradient checks, and regularization-parameter selection. |

## Related work

- [fgm_dic](https://github.com/zhugx-zju/fgm_dic) — Reconstructing two-dimensional modulus fields from experimental digital image correlation (DIC) displacement data.
- [fgm-inverse-fenics](https://github.com/zhugx-zju/fgm-inverse-fenics) — Comparing manual FEM, FEniCSx, and physics-informed neural networks on a shared modulus-inversion problem.
- [Direct-FEM](https://github.com/zhugx-zju/Direct-FEM) and [adjoint-method-Matlab](https://github.com/zhugx-zju/adjoint-method-Matlab) — Companion implementations for plane inverse problems and adjoint-based modulus identification in MATLAB.
